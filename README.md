# e호조(23310) 세출예산 세목별 예산관리대장 및 연말(12.31) 지출·잔액 예측 시스템

e호조(지방재정관리시스템)의 23310 화면에서 다운로드한 지출내역 엑셀 파일을 분석하여, 통계목(201-01 사무관리비 등) 하위의 **세목(산출기초 항목)별 예산 집행 관리**, **온나라 문서 적요 키워드(AND/OR/NOT) 자동 분류**, **1~12월 월별 지출 통계 매트릭스**, 그리고 **12월 31일 기준 연말 예상 지출액 및 예상 잔액(불용액) 시뮬레이션**을 제공하는 데스크톱 전용 소프트웨어입니다.

---

## 🌟 주요 기능

1. **상단 원클릭 툴바**
   - **`[📁 e호조 파일 선택]`**: 분석할 23310 엑셀/CSV 파일 선택
   - **`[▶ 업로드 파일 분석 시작]`**: 파일 로드 $\rightarrow$ 키워드 자동분류 $\rightarrow$ 월별 집계 $\rightarrow$ 12.31 연말 예측 $\rightarrow$ 서식 엑셀 자동 저장
   - **`[📊 엑셀 파일 열기]`**: 방금 생성된 최신 예산관리대장 엑셀 파일 즉시 실행
   - **`[📂 저장 폴더 열기]`**: 결과물이 저장된 탐색기 폴더 열기
   - **`[💡 샘플 엑셀 생성]`**: 25개 이상의 실무 지출건이 포함된 테스트용 엑셀 즉시 생성

2. **중앙 서식형 테이블 뷰**
   - **`📋 세목별 예산관리대장 (연말예측)`**: 통계목/세목 계층 트리, 배정예산, 기집행액, 현재잔액, 집행률, 연말 예상지출/잔액, 상태판정(양호/불용위험/초과위험)
   - **`📅 월별 지출 예산 통계표 (1~12월)`**: 통계목 및 세목별 1월부터 12월까지의 월별 지출액 및 누적 집행 현황 매트릭스
   - **`📝 e호조 지출 수집 내역`**: 23310에서 가져온 모든 건의 결의일자, 통계목, 세목, 적요, 채권자, 지출액, 매칭규칙 (실시간 검색/필터 지원)
   - **`🔮 연말 계획 설정`**: 매월 반복되는 정기 고정비(월정액 $\times$ 잔여월수) 및 하반기 집행예정 사업비 계획 관리
   - **`⚙ 세목 & 키워드 규칙 설정`**: `(토너 OR 복사용지) AND NOT 현수막`, `다과 OR 간담회 OR 음료` 등 자유로운 불리언 규칙 등록

3. **하단 실시간 진행 로그**
   - 파일 로드 건수, 자동분류 성공 건수, 미분류 건수, 12.31 계산 상태, 엑셀 저장 완료 등을 시간별 컬러 로그로 실시간 표시

4. **공문서 서식 엑셀 자동 출력 (`output/`)**
   - **시트 1**: 세목별 예산관리대장 (연말 예측 서식)
   - **시트 2**: 월별 지출현황 (1~12월 매트릭스)
   - **시트 3**: e호조 수집 지출내역 상세 원장

## 🚀 실행 및 빌드 방법

### 1. 즉시 실행 (Python 환경)
- [실행하기.bat](file:///c:/Users/USER/Desktop/4기%20이원재/3일차/프로젝트260828/실행하기.bat) 파일을 더블 클릭하여 실행합니다.

### 2. 단독 실행 파일 (`예산관리대장.exe`) 빌드
- [build_exe.bat](file:///c:/Users/USER/Desktop/4기%20이원재/3일차/프로젝트260828/build_exe.bat) 파일을 더블 클릭합니다.
- 빌드가 완료되면 `dist/예산관리대장.exe` 파일이 생성됩니다.
- 생성된 `.exe` 파일은 Python이 설치되지 않은 다른 행정망 PC에서도 단독으로 실행 가능합니다.
