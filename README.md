# e호조 세출예산 세목별 예산관리대장 및 연말(12.31) 지출·잔액 예측 시스템

e호조(지방재정관리시스템)에서 세부사업별로 내려받은 **지출 집행현황 PDF 여러 개를 한 번에 분석**하여 통계목별 예산 집행, 1~12월 월별 통계, 12월 31일 기준 예상 지출액과 잔액을 보여주는 오프라인 데스크톱 프로그램입니다.

---

## 🌟 주요 기능

1. **본예산·추경 PDF 자동 등록**
   - 지방재정 표준 명세서의 `세부사업 → 편성목(3자리) → 통계목(2자리)` 계층 자동 인식
   - 천원 단위 예산액을 원 단위로 변환해 본예산 마스터에 등록
   - 세부사업·편성목·통계목별 예산액을 검토 화면에서 확인 후 일괄 반영
   - 추경 PDF의 `추경후 예산액 / 기정액 / 비교증감`을 인식해 확정 본예산에 차수별 누적 반영
   - 본예산 미확정, 연도 불일치, 기정액 불일치 또는 미등록 통계목은 추경 반영 차단
   - 본예산 미확정 상태에서는 추경 및 지출현황 등록 차단

2. **세부사업별 지출현황 PDF 일괄 업로드**
   - **`[▶ 3단계: e호조 지출현황(PDF) 업로드]`**에서 PDF 여러 개 동시 선택
   - PDF의 사업명, 통계목, 적요, 결의금액, 지급일자, 지급명령번호 자동 인식
   - 같은 세부사업을 다시 올리면 최신 PDF 내용으로 교체하고, 중복 지급 행은 자동 제외
   - 동일한 통계목이 여러 세부사업에 있어도 집행액이 서로 섞이지 않도록 사업명까지 함께 매칭

3. **다른 PC에서도 그대로 열리는 단일 저장 파일**
   - **`[💾 다른 이름으로 저장]`**으로 `.ebudget` 파일 생성
   - 본예산, 추경, 지출 내역, 분류규칙, 정기지출 및 집행예정 계획을 파일 하나에 저장
   - 다른 PC에서는 프로그램과 `.ebudget` 파일을 함께 전달한 후 **`[📂 예산파일 열기]`**로 복원
   - 인터넷 연결이나 원본 PDF 경로가 없어도 저장된 분석 내용을 그대로 확인 가능

4. **상단 원클릭 도구**
   - **`[📊 엑셀 파일 열기]`**: 방금 생성된 최신 예산관리대장 엑셀 파일 즉시 실행
   - **`[📂 저장 폴더 열기]`**: 결과물이 저장된 탐색기 폴더 열기

5. **중앙 서식형 테이블 뷰**
   - **`📋 세목별 예산관리대장 (연말예측)`**: 통계목/세목 계층 트리, 배정예산, 기집행액, 현재잔액, 집행률, 연말 예상지출/잔액, 상태판정(양호/불용위험/초과위험)
   - **`📅 월별 지출 예산 통계표 (1~12월)`**: 통계목 및 세목별 1월부터 12월까지의 월별 지출액 및 누적 집행 현황 매트릭스
   - **`📝 e호조 지출 수집 내역`**: PDF에서 가져온 세부사업, 지급일자, 통계목, 적요, 지출액, 매칭규칙
   - **`🔮 연말 계획 설정`**: 매월 반복되는 정기 고정비(월정액 $\times$ 잔여월수) 및 하반기 집행예정 사업비 계획 관리
   - **`⚙ 세목 & 키워드 규칙 설정`**: `(토너 OR 복사용지) AND NOT 현수막`, `다과 OR 간담회 OR 음료` 등 자유로운 불리언 규칙 등록

6. **하단 실시간 진행 로그**
   - 파일 로드 건수, 자동분류 성공 건수, 미분류 건수, 12.31 계산 상태, 엑셀 저장 완료 등을 시간별 컬러 로그로 실시간 표시

7. **공문서 서식 엑셀 자동 출력 (`output/`)**
   - **시트 1**: 세목별 예산관리대장 (연말 예측 서식)
   - **시트 2**: 월별 지출현황 (1~12월 매트릭스)
   - **시트 3**: e호조 수집 지출내역 상세 원장

## 🚀 실행 및 빌드 방법

### 1. 즉시 실행 (Python 환경)
- `실행하기.bat` 파일을 더블 클릭하여 실행합니다.

### 2. 단독 실행 파일 (`예산관리대장.exe`) 빌드
- `build_exe.bat` 파일을 더블 클릭합니다.
- 빌드가 완료되면 `dist/예산관리대장.exe` 파일이 생성됩니다.
- 생성된 `.exe` 파일은 Python이 설치되지 않은 다른 행정망 PC에서도 단독으로 실행 가능합니다.
